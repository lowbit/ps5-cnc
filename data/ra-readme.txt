This folder holds Red Alert's game files. PS5 Native RA fills it itself: start it and choose
Download the free Red Alert, Send files from a PC or phone, Download from a link or Import from a
USB drive. Disc images, archives and game folders copied over FTP into the title's import folder
(/data/homebrew/PPSA99096/import) are added the next time it starts.

The layout, for copying files here by hand (names in any case):

  redalert.mix            from INSTALL/REDALERT.MIX on either Red Alert disc
  allied/main.mix         MAIN.MIX from the Allied disc
  soviet/main.mix         MAIN.MIX from the Soviet disc
  counterstrike/main.mix  MAIN.MIX from the Counterstrike disc (optional)
  aftermath/main.mix      MAIN.MIX from the Aftermath disc (optional)
  main.mix                a MAIN.MIX holding every disc (The First Decade's, the
                          Origin version's), or the demo's
  expand.mix              Counterstrike's missions (optional)
  expand2.mix, hires1.mix, lores1.mix   Aftermath's units and missions (optional)

One disc is enough to start. The 2008 freeware Allied and Soviet discs hold
everything the base game has: both campaigns, the movies and the music.

Settings and saves are kept in the title's save data, not here.
